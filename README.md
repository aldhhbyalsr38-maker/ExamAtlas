# ExamAtlas

Static bilingual learning website with Progressive Web App (PWA) support.

## Publish with GitHub Pages
1. Upload the contents of this folder to the repository root on the `main` branch.
2. In GitHub, open Settings → Pages.
3. Set the build and deployment source to **GitHub Actions**.
4. Open Actions and confirm the **Deploy ExamAtlas to GitHub Pages** workflow completes.

## Offline use
Open the deployed site once while online. The service worker caches the app shell and same-origin resources. External links (such as third-party job boards and official websites) still require internet access.
